# weather-ar

A weather app made in Unity. Users can scan names of places, and the app will display the current weather information for the places, if the information is available. The Google Cloud Vision API is used to detect the scanned text, which is then filtered and used on a weatherapi call to gather the weather information. The Github repository https://github.com/codemaker2015/google-cloud-vision-api-ocr-unity3d-demo is used as the base on which the project was created.

## Tech Stack

**Platform:** Unity

**Programming language:** C#

**API:** Google Cloud Vision, weatherAPI
